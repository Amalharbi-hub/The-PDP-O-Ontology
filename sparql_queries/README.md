# SPARQL Queries for PDP-O Evaluation

This folder contains the SPARQL queries used to evaluate the **Date Palm Pest and Disease Ontology (PDP-O)**.

The queries correspond to the competency questions (CQs) used in the PDP-O evaluation. They cover disease/pest diagnosis, control methods, symptoms, causal agents, outbreak timing, susceptible cultivars, affected plant parts, and ontology reasoning tests.
